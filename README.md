# Completion and Progress Scoring support for Rise SCORM packages

Leverage the SCORM API to augment completion and progress tracking in Articulate Rise packages.  

## Issues with RISE SCORM packages (and Brightspace, sort of)

This code addresses a two main issues with SCORM packages generated by Articulate Rise and imported into D2L Brightspace

### Setting Scores for Rise Packages without Quiz Blocks

If you are using Knowledge Checks instead of Quiz Blocks in Rise, you won’t get the completion as a score in the Brightspace grade book.  Specifically,

* Rise-exported SCORM packages that don’t use Quiz Blocks will not set a score on completion.  
* While Brightspace will register a completion for this sort of package, it doesn’t register a score in the grades area.  
* This means there is no way to leverage SCORM completion events in Brightspace as release criteria or elsewhere.  The only way to access SCORM completions is via reporting.

There is no option in Rise to force it to set the score on completion when you publish/export a package. 

### Polling Progress in Rise SCORM packages

If you want to be able to tell if/how someone has progressed through your Rise SCORM package, there are some challenges:

* Rise does not update `cmi.progress_measure`, which makes it difficult to tell how far along a participant progressed through the training if they exit without completing.
* You can roughly get a sense for how many “lessons” someone has accessed by counting `cmi.location` events/changes (though no further granularity exists if you are using knowledge checks).
* There is no way to tell how many total lessons are in an exported Rise package.
* There is no built-in way to persist progress data (even just a count of lessons accessed) when someone leaves and comes back to the training.

So what we end up doing here is tracking the number of lessons accessed, storing that data by “piggybacking” on `cmi.suspend_data` , and in the event the student exits without a completion, setting that count as the score.  A `cmi.completion_status` event of “complete” will always trigger a score being set at 100.

We can then configure the gradebook in Brightspace to use a custom schema that shows the column as complete/incomplete based on whether they got the 100 (completion), or just the raw lesson count score (incomplete).

## Install/Configuration

### Modify your SCORM package

1. Publish your Rise as SCORM 2004 v4.  In theory, most of this should work with 1.2 but it hasn’t been tested.
2. Un-pack the exported zip file.
3. In `scormcontent/index.html`, add a `<script></script>` tag just before `</body>`.
4. Put the the Javascript in that script tag.
5. Save the index.html file
6. zip the package back up, taking care that the `scormcontent/` directory and imsmanifest.xml is at the root (top level) of the zipped files.

### Upload to Brightspace 

1. Go to the Brightspace course you want to publish this in, and navigate to the content area/module where it will live.
2. Click Upload/Create -> New SCORM/xAPI Object
3. Click Bulk Upload, and add your zipped package
4. Select the package you uploaded and add it to your course.
5. Be sure to select the option to add a grade column for this package.

### Create a Schema 

Now that the package is in place, and a grade column has been attached, you create a schema:

1. Go to Course Admin -> Grades -> Schemes
2. New Scheme
3. Set a title, such as “Complete/Incomplete (100% only)
4. Set the ranges:


| **#** | **Symbol***  | **Start %***  | **Color**    | **Assigned**<br>**Value %** |
|:-----:|:------------:|:-------------:|:------------:|:---------------------------:|
| **1** | Incomplete   | 0             | ==🔴(Red)==   | 99<br>                      |
| **2** | Complete     | 100<br>       | ==🟢(Green)== | 100<br>                     |

5. Save & Close
### Edit the Grade Column

Last step is to set the column to use the schema, and configure score visibility so participants only see the schema ranges to avoid confusion when they have a partial score.

1. Go to Course Admin -> Grades
2. Edit the column associated with the package/training.
3. Set the Grade Scheme to the one you created above. 
4. Check the box for “Override display options for this item”
5. Un-Check Points grade
6. Check Grade scheme symbol
7. Check Grade scheme color
8. Save & Close

Test with a student view account to confirm score posting and display.
